# SSH Authorized Keys Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a role and playbook to deploy and remove SSH authorized keys for the Ansible remote user, driven by a version-controlled list of `{username, pub_key}` entries.

**Architecture:** A minimal `ssh_keys` role holds the key definitions in `files/authorized_keys.yml` and the task logic in `tasks/main.yml`. A thin playbook at `playbooks/ssh_keys.yml` is the entry point. The `ansible.posix.authorized_key` module manages the actual key state on remote hosts.

**Tech Stack:** Ansible, `ansible.posix` collection (`ansible.posix.authorized_key`)

### Task 2: Create the key definitions file

**Files:**
- Create: `roles/ssh_keys/files/authorized_keys.yml`

- [ ] **Step 1: Create the directory**

```bash
mkdir -p roles/ssh_keys/files
```

- [ ] **Step 2: Create the file**

Create `roles/ssh_keys/files/authorized_keys.yml`:

```yaml
---
ssh_authorized_keys:
  - username: alice
    pub_key: "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... alice@example.com"
  - username: bob
    pub_key: "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAI... bob@example.com"
```

Replace the placeholder `pub_key` values with real public keys before using in production. The `username` field is a human-readable label — it identifies who owns the key in this file, not a Linux account name.

- [ ] **Step 3: Commit**

```bash
git add roles/ssh_keys/files/authorized_keys.yml
git commit -m "feat: add ssh_keys role files directory with key definitions"
```

### Task 3: Create the role task

**Files:**
- Create: `roles/ssh_keys/tasks/main.yml`

- [ ] **Step 1: Create the tasks directory**

```bash
mkdir -p roles/ssh_keys/tasks
```

- [ ] **Step 2: Write the task file**

Create `roles/ssh_keys/tasks/main.yml`:

```yaml
---
- name: Load authorized key definitions
  ansible.builtin.set_fact:
    _all_keys: "{{ lookup('file', role_path + '/files/authorized_keys.yml') | from_yaml }}"

- name: Filter keys by ssh_users (if specified)
  ansible.builtin.set_fact:
    _keys_to_apply: >-
      {{
        _all_keys.ssh_authorized_keys
        if ssh_users is not defined
        else _all_keys.ssh_authorized_keys | selectattr('username', 'in', ssh_users) | list
      }}

- name: Manage SSH authorized keys
  ansible.posix.authorized_key:
    user: "{{ ansible_user }}"
    key: "{{ item.pub_key }}"
    state: "{{ state | default('present') }}"
  loop: "{{ _keys_to_apply }}"
  loop_control:
    label: "{{ item.username }}"
```

- [ ] **Step 3: Syntax-check the role tasks**

```bash
ansible-playbook --syntax-check -i localhost, -c local \
  -e '{"target_hosts":"localhost","ansible_user":"ubuntu"}' \
  /dev/stdin <<'EOF'
- hosts: localhost
  roles:
    - ssh_keys
EOF
```

Expected: `playbook: -` with no errors.

- [ ] **Step 4: Lint the task file**

```bash
pipenv run ansible-lint roles/ssh_keys/tasks/main.yml
```

Expected: no violations (warnings about `set_fact` naming are acceptable if they appear).

- [ ] **Step 5: Commit**

```bash
git add roles/ssh_keys/tasks/main.yml
git commit -m "feat: add ssh_keys role tasks to manage authorized keys"
```

### Task 4: Create the playbook

**Files:**
- Create: `playbooks/ssh_keys.yml`

- [ ] **Step 1: Write the playbook**

Create `playbooks/ssh_keys.yml`:

```yaml
# Usage: ansible-playbook playbooks/ssh_keys.yml -e target_hosts=<group>
#
# Variables:
#   target_hosts  (required) — inventory host or group
#   state         (optional, default: present) — present | absent
#   ssh_users     (optional) — list of usernames to act on; omit for all
#
# Examples:
#   Add all keys:
#     ansible-playbook playbooks/ssh_keys.yml -e target_hosts=gpu-nodes
#
#   Add only alice's key:
#     ansible-playbook playbooks/ssh_keys.yml -e target_hosts=gpu-nodes \
#       -e '{"ssh_users":["alice"]}'
#
#   Remove bob's key:
#     ansible-playbook playbooks/ssh_keys.yml -e target_hosts=gpu-nodes \
#       -e '{"ssh_users":["bob"],"state":"absent"}'
---
- name: Manage SSH authorized keys
  hosts: "{{ target_hosts | mandatory('Required: -e target_hosts=<group_or_host>') }}"
  become: true

  roles:
    - ssh_keys
```

- [ ] **Step 2: Syntax-check the playbook**

```bash
pipenv run ansible-playbook --syntax-check \
  -e target_hosts=localhost \
  playbooks/ssh_keys.yml
```

Expected: `playbook: playbooks/ssh_keys.yml` with no errors.

- [ ] **Step 3: Lint the playbook**

```bash
pipenv run ansible-lint playbooks/ssh_keys.yml
```

Expected: no violations.

- [ ] **Step 4: Commit**

```bash
git add playbooks/ssh_keys.yml
git commit -m "feat: add ssh_keys playbook to deploy and remove authorized keys"
```
